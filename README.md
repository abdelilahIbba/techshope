# 🛒 TechShope — فرع التطوير (`sck`)

مرحباً بك في فرع **`sck`** لمشروع **TechShope**. يضم هذا الفرع كافة التحسينات والميزات المتقدمة الجديدة التي تم تطويرها واختبارها بعناية، مع توثيق تفصيلي لكل ميزة لتسهيل العمل المشترك والمراجعة (Code Review) بين أعضاء الفريق.

---

## 📌 أبرز التعديلات والإضافات في هذا الفرع (Key Features)

### 1. 📷 ماسح الباركود بالكاميرا والهاتف الذكي (Camera Barcode Scanner)
* **المسح عبر كاميرا الحاسوب (PC Webcam):** إمكانية قراءة الباركود مباشرة من كاميرا الويب المدمجة في شاشة الـ POS باستخدام مكتبة ZXing والـ BarcodeDetector API.
* **المسح اللاسلكي عبر كاميرا الهاتف (Mobile Wireless Scanner):**
  * إمكانية تحويل أي هاتف ذكي إلى ماسح باركود لاسلكي دون الحاجة لتحميل أي تطبيق.
  * توليد رمز QR ديناميكي مؤمن برمز سري (`token`) مؤقت لكل جلسة.
  * نقل الباركود فورياً من الهاتف إلى شاشة البيع (POS) عبر قناة بث أحادي مباشر **Server-Sent Events (SSE)**.
  * استثناء مسار الإرسال (`/pos/scanner/push`) من التحقق من CSRF مع حمايته برمز الجلسة ومعدل طلبات محدد (Rate Limiting).
* **التوافق التام:** لا يتعارض النظام الجديد إطلاقاً مع أجهزة قراءة الباركود اليدوية التقليدية (USB Barcode Scanners).

### 2. 🐳 عزل بيئة العمل والحاويات بالكامل (Docker Isolation)
لضمان إمكانية تشغيل هذا المشروع جنباً إلى جنب مع أي نسخة أخرى على نفس الجهاز دون أي تداخل في المنافذ أو قواعد البيانات:
* **تسمية مخصصة للحاويات:** تم تعديل بادئة الحاويات إلى `techshope_sck_*` (`app`, `web`, `pgsql`, `queue`, `vite`).
* **تغيير منافذ الوصول:**
  * منفذ الويب الرئيسي: **`18081`** (بدلاً من 18080).
  * منفذ قاعدة البيانات: **`15433`** (بدلاً من 15432).
  * منفذ خادم Vite: **`15174`** (بدلاً من 15173).
* **قاعدة بيانات معزولة:** قاعدة بيانات مستقلة باسم **`techshope_sck`** مع وحدات تخزين دائمة مستقلة (Docker Volumes).

### 3. 🏷️ نظام العروض والتخفيضات (Promotions & Soldes)
* إضافة حقول `promo_price` و `is_on_promo` لجدول المنتجات `products`.
* واجهة مستخدم مخصصة لإدارة التخفيضات وحساب نسب الخصم (`/pos/promos`).
* تحديث شاشة نقطة البيع (POS) لتطبيق السعر الفعلي المخفض (`effective_price`) تلقائياً في السلة والفاتورة دون التأثير على حساب الأرباح والمبيعات.
* وضع شارة بصرية واضحة (`PROMO`) على كروت المنتجات المخفضة.

### 4. 📱 إدارة الطلبات الخارجية (External Orders - Instagram & WhatsApp)
* إضافة نموذج وقاعدة بيانات خاصة بالطلبات الخارجية `ExternalOrder` والجدول `external_orders`.
* واجهة متكاملة (`/pos/external-orders`) لإدارة ومتابعة طلبات وسائل التواصل الاجتماعي (إنستغرام، واتساب، قنوات أخرى).
* دورة حياة ومتابعة لحالة الطلب: قيد الانتظار (`Pending`) ⬅️ تم الشحن (`Shipped`) ⬅️ تم التوصيل (`Delivered`) أو الإلغاء (`Cancelled`).

### 5. 🧪 إصلاح اختبارات النظام الشاملة (157/157 Tests Passing)
* حل مشكلة تداخل بيئة قاعدة البيانات PostgreSQL في بيئة الاختبار واستخدام SQLite In-Memory عبر `.env.testing`.
* حل مشكلة التحقق من الترخيص الافتراضي (`License id=1`) في الاختبارات.
* تعديل وتحديث الـ Seeders لتطابق متطلبات التحقق والاختبار بدقة.
* نجاح تشغيل كافة الاختبارات بنسبة **100%** (157 اختباراً و 1004 توكيد).

## 🚀 طريقة التشغيل عبر Docker

```bash
# 1. نسخ ملف الإعدادات
cp .env.docker.example .env

# 2. تشغيل الحاويات في الخلفية
docker compose up -d

# 3. فتح التطبيق في المتصفح
# الرابط الرئيسي:
http://localhost:18081

# نقطة البيع (POS):
http://localhost:18081/pos
```
